# FRONTIER

AI×ウェルネスの新規事業企画。
AIがパーソナライズしたヨガ・ウェルネスプランを、アプリと拠点の両方で提供する。

## 事業概要

| 項目 | 内容 |
| --- | --- |
| テーマ | AI×ウェルネス |
| ターゲット | 忙しい社会人女性、デジタル疲れを感じている人、法人 |
| エリア | 都心部（東京・大阪・福岡・横浜）、地方の主要都市 |
| 提携候補 | AI開発会社、他の不動産会社、区分投資事業部、沖縄コンドミニアム |

## 提供価値

- AIが作るパーソナライズされた健康プラン（リアルタイムのポーズフィードバック、バイタルに合わせて最適化されたプログラム）
- 心身の健康とゆっくりした時間
- 同じ考えを持つ人との出会い、コミュニティ

## 強み

- プロ監修の指導を一人ひとりが好きなだけ受けられる
- 予約不要で自分のスケジュールに合わせてできる
- 場所を選ばない
- 感情や生体反応に寄り添うAI対話
- 人件費を抑えられるので価格を下げられる

## 収益モデル

- アプリ月額料金（プラン型サブスク）
  1. AIのみ
  2. AI＋セミナー
  3. セミナーのみ（単発購入も可）
- セミナー受講料
- 法人向け月額契約、システム販売
- 提携施設へのシステム導入料
- 年額プラン、コース型プラン（姿勢改善、ダイエットなど）を検討中

## アプリの機能（案）

- AIによる自分専用メニューの作成
- ヨガ専門家の動作・監修データをもとにしたポーズフィードバック
- 心拍・ストレス度測定と連動するAIスクリプト
- 運動記録
- 対話型ジャーナリング
- 食事提案（将来）

## ロードマップ

| 時期 | 主な取り組み | 目標 |
| --- | --- | --- |
| 1年目 | アプリ開発とテスト、市場調査、拠点1か所でのテスト運用、SNSマーケティング、初期ユーザーへのヒアリング | ダウンロード数5,000 |
| 3年目 | 都心4都市で展開、セミナー開催、データをもとにAIを改善、バイタル連携の開発 | 拠点20か所、ダウンロード数1万 |
| 5年目 | 法人向けに拡大、対話型エージェントでメンタルケア、禅コース追加、ホテル・リゾートでの展開、食事プラン提供 | 拠点100か所、ダウンロード数10万、法人50社、継続率70% |
| 10年目 | カフェ・サウナなどとの複合施設、プロテインなどとのコラボ | 拠点500か所、法人100社、ダウンロード数50万、継続率80% |
| その後 | 禅にフォーカスして海外展開 | |

## 市場調査の項目

- ヨガへの関心度、実施率の推移
- デジタル疲れ、スマホから離れたいニーズ
- ストレスの度合い、健康意識
- ヨガ市場の規模と将来性
- ヨガ利用者の不満や課題
- 追い風になる要因（国際ヨガデー 6月21日など）
- エリアの選定理由
- 企業の人事・健康担当者へのヒアリング（福利厚生の内容、従業員の健康課題、社内の運動スペース、導入形式、予算、重視する点）

## 競合

- 一般的なヨガスタジオ
- オンラインヨガ
- 瞑想アプリ
- ジム、YouTubeチャンネル
- セミナーやツアー
- コワーキングスペース（長時間滞在できる点で比較が必要）

## 検討中の課題

- 個人向けと法人向け、どちらから始めるか
- AI開発の費用と期間（外部委託の場合の初期費用、保守費用、データセンターの要否）
- 不動産会社がこの事業をやる理由
- 自社物件の価値向上につなげるのか、単独事業で利益を出すのか
- 拠点を賃貸にするか、自社物件にするか
- コストから逆算した収支計画
